# Fortune Cookie Wisdom for Developers

Entry for the [Fortune Cookie Wisdom for Developers bounty](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) on make.fun: a single original line of fortune-cookie wisdom aimed at a software developer, at most 120 characters.

> Your lucky number today is the line count of the function you are afraid to touch.

Run it with `node main.ts`. It prints exactly that line.
